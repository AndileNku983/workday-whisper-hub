# Workday Whisper Hub

AI Productivity Assistant Website Application

1. Role

Act as an expert full-stack developer, AI solutions architect, and UI/UX designer specialising in workplace productivity applications.

2. Objective

Build a modern, responsive AI Productivity Assistant that helps employees and businesses manage emails, communicate with AI, plan tasks, and improve workplace efficiency.

3. Context

The application combines smart email assistance, an AI chatbot, and an intelligent task planner in one central platform. It is designed for employees, managers, and teams who want to save time, automate repetitive tasks, and improve productivity.

4. Requirements

Smart Email: Generate, rewrite, proofread, and summarise emails; suggest replies and prioritise messages.

AI Chatbot: Answer questions, summarise documents, generate reports, and draft professional workplace communications.

AI Task Planner: Create, prioritise, assign, and track tasks; manage deadlines, reminders, calendars, and weekly schedules.

Dashboard: Display daily tasks, urgent emails, upcoming deadlines, notifications, and productivity statistics.

User Management: Include secure login, user profiles, settings, and privacy controls.

Design: Use a professional SaaS interface with navy blue, white, and purple accents, a collapsible sidebar, responsive layouts, and dark/light modes.

Technology: Use React, TypeScript, Tailwind CSS, and Supabase, with AI API integration and optional Gmail, Outlook, and calendar connectivity.

5. Output

Deliver a functional, professional, mobile-friendly web application with working navigation, chatbot interactions, task management, and dashboard updates. Include realistic demo data where necessary, secure API handling, and setup instructions for external integrations. Ensure the application is scalable and suitable for workplace use.
